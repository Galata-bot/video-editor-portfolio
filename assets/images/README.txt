Put your portfolio thumbnails, portrait photo, showreel poster, and social
preview image in this folder.

Then reference them in:
  - portfolio-data.js  → each project's "thumbnail" field
  - config.js          → SITE_CONFIG.showreel.poster and SITE_CONFIG.socialImage
  - index.html          → the About section portrait (see the comment there)

Recommended formats: .jpg or .webp, compressed for the web (a few hundred KB
per image is usually enough — large unoptimized images will slow the site).
